## ✨ Key Features

* **Secure Authentication:** Robust JWT-based authentication system.
* **Data Isolation:** Complete data privacy and isolation per user.
* **Dynamic Calendar:** Interactive Month and Week views for granular schedule management.
* **Task Recurrence:** Built-in support for daily, weekly, and monthly repeating tasks.
* **Decoupled Architecture:** Clean separation of concerns with a Vanilla JS/CSS client and a RESTful Node/Express API.

## 🛠️ Tech Stack

**Front-End:**
* HTML5 & CSS3
* JavaScript (ES6+)
* Flatpickr (for date/time selection)

**Back-End (REST API):**
* Node.js & Express.js
* MongoDB with Mongoose
* JSON Web Tokens (JWT) & Bcrypt (Security)
